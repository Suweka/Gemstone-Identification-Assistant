Optional real gemstone photos.

The web interface draws each gem as a picture automatically. To show a real
photo instead, save it in this folder named after the example or gem key,
as .jpg, .jpeg, .png or .webp, for example:

  blue_sapphire.jpg     synthetic_ruby.jpg    star_sapphire.jpg
  padparadscha.jpg      red_spinel.jpg        hessonite.jpg
  alexandrite.jpg       cats_eye.jpg          moonstone.jpg
  amethyst.jpg          aquamarine.jpg        glass_imitation.jpg
  cubic_zirconia.jpg    unknown_red.jpg

Result pages look for the identified variety or species name, e.g.
ruby.jpg, cats_eye_chrysoberyl.jpg, corundum.jpg.

Restart the server (or reload the page) after adding photos.
If you use photos from the internet, credit the source in your report.
