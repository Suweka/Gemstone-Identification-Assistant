1. About the system

The Gemstone Identification Assistant is an expert system that helps buyers, students and small traders identify common Sri Lankan gemstones. You describe a stone (its measurements and what you can see) and the system tells you:

  • what the stone most likely is (species and variety, for example corundum - blue sapphire);
  • whether it is likely natural, synthetic (laboratory-grown) or an imitation such as glass;
  • how certain it is, as a percentage;
  • what you should do next, for example obtain a laboratory certificate before buying;
  • exactly how it reached its answer.

It knows ten gem species (corundum, spinel, garnet, chrysoberyl, zircon, topaz, tourmaline, quartz, feldspar/moonstone and beryl), their main varieties, and two imitation materials (glass and cubic zirconia).

Important: the system gives a first opinion only. It does not replace a certificate from the National Gem and Jewellery Authority (NGJA) or another accredited gem laboratory. Always obtain a certificate before a significant purchase.

1.1 Three ways to use it

ModeUse it when...What it does
Identify"I don't know what this stone is."Takes everything you enter and works forwards to the most likely answer (forward chaining).
Verify"The seller says it's a ruby. Is it?"Starts from the claim and checks every condition it needs; if the claim fails it tells you exactly why (backward chaining).
Step by step"I want to be guided."Asks you one question at a time, only when needed, and explains why it is asking.

You can also type a question in plain English, for example "Is my stone a sapphire if the RI is 1.765 and it is blue?"

3. Installation

3.1 Install SWI-Prolog

  1. Open https://www.swi-prolog.org/download/stable in your browser.
  2. Download the installer for your computer. On Windows choose the 64-bit installer (swipl-...-1.x64.exe).
  3. Run the installer and accept the default settings.
  4. Windows only: on the "Install Options" page select "Add swipl to the system PATH for all users" (or "for the current user"). This lets you start SWI-Prolog from a terminal.
  5. Finish the installation. On macOS you can alternatively install with Homebrew (brew install swi-prolog); on Ubuntu Linux use sudo apt install swi-prolog.

[Insert a screenshot of the SWI-Prolog installer's "Add swipl to the system PATH" option here.]

3.2 Copy the project folder

  1. Copy or unzip the gem_expert folder to a convenient place, for example Documents\gem_expert.
  2. Check that the folder contains these files: main.pl, knowledge_base.pl, engine.pl, ui.pl, console.pl, diagrams.pl, examples.pl, query_parser.pl, tests.pl and an images folder.

3.3 Check the installation

  1. Open a terminal: on Windows, open the gem_expert folder in File Explorer, click the address bar, type cmd and press Enter. On macOS or Linux, open Terminal and use cd to go to the folder.
  2. Type swipl --version and press Enter. You should see a line such as SWI-Prolog version 10.1.16 for x64-win64.
If you see "'swipl' is not recognized", SWI-Prolog is not on the PATH. See Troubleshooting (Section 12).

4. Starting and stopping the system

4.1 Start the web interface (recommended)

  1. In the terminal, inside the gem_expert folder, type: 
    swipl main.pl
    You will see: 
    === Gemstone Identification Assistant loaded ===
  server(8080).   start web interface, then open http://localhost:8080
  start.          console interface
  demo.           worked example
  run_tests.      run automated tests

?-
  2. At the ?- prompt type the following, including the full stop, and press Enter: 
    server(8080).
    The system replies Web interface running: open http://localhost:8080 in your browser.
  3. Open your web browser and go to http://localhost:8080. The home page appears (Figure 1).
On Windows the first time you start the server, Windows Defender Firewall may ask whether to allow SWI-Prolog to communicate. Choose Allow for private networks. The system only listens on your own computer.
Every Prolog command ends with a full stop. If nothing happens after pressing Enter, type . and press Enter again.

4.2 Stop the system

  1. In the terminal type stop_server(8080). to stop the web server.
  2. Type halt. to leave SWI-Prolog. (Closing the terminal window also stops everything.)

6. Describing your stone

The form (Figure 3) has two groups of fields. Every field is optional. Fill in what you know and leave the rest as Unknown / not checked. The more you fill in, the more certain the answer. Each field shows what the property means (grey text) and how to measure it (HOW).

Figure 3. The input form

Table 2. Input fields

FieldWhat it isHow to obtain itTips
Refractive index (RI)How strongly the stone bends light. Each gem has its own range.Gem refractometer with contact liquid; use the highest reading.Enter three decimals, e.g. 1.765. Allowed range 1.3-3.0. Leave blank if the scale shows no edge (over the limit) or you have no refractometer.
Specific gravity (SG)How heavy the stone is compared with the same volume of water.Hydrostatic balance: SG = weight in air / (weight in air - weight in water).Enter two decimals, e.g. 4.00. Allowed range 1.0-8.0.
Optic characterWhether light passes as one ray (singly refractive) or is split in two (doubly refractive).Polariscope: rotate the stone between crossed filters. A conoscope shows uniaxial or biaxial.If you only know it is doubly refractive, choose Doubly refractive (axis not known).
ColourThe main body colour.Look in daylight against a white background.Choose the closest colour.
Optical effectStar, cat's-eye, colour change or moonstone glow.Look under a single light source and rotate the stone; compare daylight and lamp light for colour change.Choose No special effect if you looked and saw none.
InclusionsTiny features inside the stone that reveal how it formed.Examine with a 10x jeweller's loupe.Choose the most obvious type. None visible means you looked and the stone is clean.

Below the fields are three action panels: Identify my stone, Check a claim (choose a gem in the list, then Verify) and Ask me step by step. Clear the form empties all fields.

7.3 Using the reasoning diagram

Figure 5. Forward-chaining diagram

Your inputs are the blue boxes at the top. Each dark oval is a rule; its gold number shows the order in which it fired. Arrows show which facts made the rule fire and which new fact it added. Use the buttons:

  • Play step by step: replays the reasoning automatically, one rule at a time, with a caption explaining each step.
  • Back / Next: move one step at a time yourself.
  • Show all: shows the complete diagram again.

Hover the mouse over any box to see its full details.

7.4 When some data is missing

If you leave out the RI, SG or optic character, the system cannot confirm a species. Instead it lists Ranked possibilities (Figure 6): every gem consistent with what you entered, ordered by certainty, with the evidence for each. Measure the missing properties to narrow the list.

Figure 6. Ranked possibilities for a blue, uniaxial stone with no RI or SG

8. Checking a claim (Verify)

  1. Fill in the fields you know.
  2. In the Check a claim panel choose the gem the seller claims, e.g. Ruby.
  3. Press Verify.

The answer is a clear Yes (green tick) or No (red cross). For a No, the page shows the main reason, what your data points to instead, and a Why not? list tracing the failure back through the rules (Figure 7). The backward-chaining diagram shows the question at the top, the rules tried below it, and each condition marked proved (green), failed (red) or never checked (dashed grey).

Figure 7. A failed verification: a red spinel offered as a ruby

9. Step-by-step consultation

  1. Click Step by step in the top bar (or Ask me step by step on the home page).
  2. Choose what you want to find out. Find the species lets the system test one gem hypothesis after another. You can also choose a particular gem.
  3. Answer each question and press Answer, or press I don't know.
  4. Open Why are you asking this? at any time to see which rule the system is testing and why it needs the answer (Figure 8).
  5. When the system has enough information it shows the answer, how many questions it needed, and a diagram of its reasoning.

Figure 8. A consultation question with its explanation

The system asks only what it needs. For example, when checking for ruby, answering Isotropic to the first question ends the consultation immediately, because a ruby must be doubly refractive.

10. Asking in plain English

Type a question into the box on the home page and press Ask. The system shows what it understood (Figure 9) and then answers. Examples:

  • Is my stone a sapphire if the RI is 1.765 and it is blue?
  • What is a singly refractive red stone with SG 3.60?
  • Could it be glass? isotropic, RI 1.52, gas bubbles
  • RI 1.52, SG 2.57, biaxial, colourless, with adularescence

Understood words include RI / refractive index, SG / specific gravity, singly or doubly refractive, uniaxial, biaxial, colour names, star, cat's eye, colour change, adularescence, silk, crystals, fingerprints, gas bubbles, curved lines, swirl marks, discoid fractures, clean, and gem names. Words the system did not use are listed so you can rephrase.

Figure 9. A plain-English question and how it was understood

11. Worked examples

The Example stones to try section of the home page has 14 ready-made stones (Figure 10). Press Try it on any card to copy its readings into the form, then press Identify stone or Verify.

Figure 10. Example stones

11.1 Example 1: a natural blue sapphire

InputRI 1.765, SG 4.00, Uniaxial, Blue, Silk
ResultBlue sapphire (species corundum) - Strong match, 90% certain; origin Likely natural (76%).
RecommendationObtain an NGJA or other accredited laboratory certificate before purchase.
WhyRule r1 identified corundum from the optic character, RI and SG; rule r24 named the blue variety; rule r46 used the rutile silk as evidence of natural origin.

11.2 Example 2: a glass imitation

InputRI 1.60, Isotropic, Round gas bubbles (SG not measured)
ResultImitation: Glass - 85% certain; origin Imitation (not a natural gemstone) (Figure 11).
RecommendationThis is an imitation with little gem value; do not pay gemstone prices.

Figure 11. A glass imitation is detected

11.3 Example 3: checking a claim that fails

InputRI 1.718, SG 3.60, Isotropic, Red; claim: Ruby
ResultNo - the stone does not match ruby. Main reason: a ruby must be doubly refractive (uniaxial) but the stone is singly refractive. The data points to Red spinel instead (Figure 7).

12. Troubleshooting

Table 4. Common problems and solutions

ProblemSolution
"'swipl' is not recognized as an internal or external command"SWI-Prolog is not on the PATH. Re-run the installer and select "Add swipl to the system PATH", then open a new terminal. Alternatively run it with its full path: "C:\Program Files\swipl\bin\swipl.exe" main.pl.
Error "port 8080 is already in use" (or similar) after server(8080).Another program uses that port. Start on a different port, e.g. server(8081)., and open http://localhost:8081.
Browser shows "This site can't be reached"The server is not running. Check that you typed server(8080). with the full stop, and that the terminal window is still open. Check the port number in the address.
Nothing happens after typing a commandProlog is waiting for the full stop. Type . and press Enter.
Error messages about files not found when running swipl main.plThe terminal is not in the gem_expert folder. Use cd to move into it, or open the terminal from that folder.
"Please check your input" pageA value is outside the allowed range (RI 1.3-3.0, SG 1.0-8.0) or is not a number. Press Go back and fix it.
Result says "We could not identify this stone"Re-check the readings (RI usually has three decimals, SG two) and the optic character. The stone may also be outside the system's scope; seek a laboratory test.
Changes to the program files do not appearIn the Prolog terminal type make. to reload changed files, then refresh the browser (Ctrl+F5). Or stop and restart the system.
Windows Firewall message on first startChoose Allow for private networks.
The page fonts look plainYou are offline; the page falls back to standard fonts. Everything still works.

13. Console mode (without a browser)

If the web interface cannot be used, the same functions are available in the terminal.

  1. Start SWI-Prolog with swipl main.pl.
  2. Type start. A menu appears: 
    What would you like to do?
  1. Identify a stone  - "I don't know what it is"      (forward chaining)
  2. Check a claim     - "The seller says it's a ruby"   (backward chaining)
  3. Step by step      - asks only what it needs; type WHY at any question
  4. Ask in English    - e.g. is it a ruby if the RI is 1.765 and it is red
  5. Run the demo      - natural blue sapphire example
  6. Quit
Choose 1-6:
  3. Type a number and press Enter (no full stop is needed inside the menu). Answer each question by typing a number or a value; press Enter on its own if you do not know.
  4. In step-by-step mode, type why at any question to see why it is being asked: 
    What is the optic character?
    0. Don't know
    1. Isotropic
    2. Uniaxial
    ...
> why
WHY I AM ASKING:
  - I am trying to find out: is it Corundum?  Rule r1 says: IF Optic: Uniaxial AND RI in
    Corundum range AND SG in Corundum range THEN Species: Corundum.
  - To test rule r1 I need to know: the optic character.
  5. After each result you can type y to see the technical trace.
  6. Choose 6 to leave the menu, then type halt.

The command demo. runs the worked blue sapphire example directly.

14. Running the automated tests

  1. Start SWI-Prolog with swipl main.pl.
  2. Type run_tests.
  3. The last line should read: 
    % All 41 tests passed

The rule base can also be exported to a spreadsheet file with export_rules_csv('rules_table.csv').
