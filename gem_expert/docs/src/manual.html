1. About the system

The Gemstone Identification Assistant is an expert system that helps buyers, students and small traders identify common Sri Lankan gemstones. You describe a stone (its measurements and what you can see) and the system tells you:

  • what the stone most likely is (species and variety, for example corundum - blue sapphire);
  • whether it is likely natural, synthetic (laboratory-grown) or an imitation such as glass;
  • how certain it is, as a percentage;
  • what you should do next, for example obtain a laboratory certificate before buying;
  • exactly how it reached its answer.

It knows ten gem species (corundum, spinel, garnet, chrysoberyl, zircon, topaz, tourmaline, quartz, feldspar/moonstone and beryl), their main varieties, and two imitation materials (glass and cubic zirconia).

Important: the system gives a first opinion only. It does not replace a certificate from the National Gem and Jewellery Authority (NGJA) or another accredited gem laboratory. Always obtain a certificate before a significant purchase.

1.1 Three ways to use it

ModeUse it when...What it does
Identify"I don't know what this stone is."Takes everything you enter and works forwards to the most likely answer (forward chaining).
Verify"The seller says it's a ruby. Is it?"Starts from the claim and checks every condition it needs; if the claim fails it tells you exactly why (backward chaining).
Step by step"I want to be guided."Asks you one question at a time, only when needed, and explains why it is asking.

You can also type a question in plain English, for example "Is my stone a sapphire if the RI is 1.765 and it is blue?"

3. Option A: use the online version (no installation)

The system is hosted on the internet, so nothing needs to be installed. Only a web browser is needed (Microsoft Edge, Google Chrome, Firefox or Safari, on a computer, tablet or phone).

  1. Open your web browser.
  2. Go to https://gemstone-identification-assistant.onrender.com
  3. The home page appears (Figure 1). Continue from Section 5.
First visit may be slow. The online version runs on a free hosting service that "sleeps" when nobody has used it for about 15 minutes. The first page can then take up to about a minute to appear while it wakes up; after that it is fast. If the page does not load, wait a moment and refresh.

The online version has every feature of the web interface. The console interface (Section 16) and the automated tests (Section 17) are only available when the system runs on your own computer (Option B). Your "recent stones" list is saved only in your own browser (Section 13).

4.2 Install SWI-Prolog

  1. Open https://www.swi-prolog.org/download/stable in your browser.
  2. Download the installer for your computer. On Windows choose the 64-bit installer (swipl-...-1.x64.exe).
  3. Run the installer and accept the default settings.
  4. Windows only: on the "Install Options" page select "Add swipl to the system PATH for all users" (or "for the current user"). This lets you start SWI-Prolog from the Command Prompt.
  5. Finish the installation. On macOS you can alternatively install with Homebrew (brew install swi-prolog); on Ubuntu Linux use sudo apt install swi-prolog.

4.3 Download the project as a ZIP file

  1. Open https://github.com/Suweka/Gemstone-Identification-Assistant in your browser.
  2. Click the green Code button, then Download ZIP. The file Gemstone-Identification-Assistant-main.zip is saved to your Downloads folder.
  3. Open the Downloads folder, right-click the ZIP file and choose Extract All..., then Extract. (On macOS, double-click the ZIP file.)
  4. Open the extracted folder Gemstone-Identification-Assistant-main, then the gem_expert folder inside it. It contains main.pl, knowledge_base.pl, engine.pl, ui.pl, console.pl, diagrams.pl, examples.pl, query_parser.pl, tests.pl and an images folder.
If you received the project as a ZIP file in another way (for example by e-mail or on a USB drive), extract it in the same way and open the gem_expert folder.

4.4 Open the Command Prompt in the project folder

The system is started from a command window opened inside the gem_expert folder. On Windows, use either method:

  • From File Explorer (easiest): with the gem_expert folder open, click the address bar at the top, type cmd and press Enter. A Command Prompt window opens already in the right folder.
  • From the Start menu: press the Windows key, type cmd and press Enter. Then type cd, a space, and the folder's location, and press Enter, for example: 
    cd %USERPROFILE%\Downloads\Gemstone-Identification-Assistant-main\gem_expert

On macOS or Linux, open Terminal and use cd to go to the gem_expert folder.

To check that SWI-Prolog is installed, type swipl --version and press Enter. You should see a line such as SWI-Prolog version 10.1.16 for x64-win64.

If you see "'swipl' is not recognized", SWI-Prolog is not on the PATH. See Troubleshooting (Section 15).

6. Describing your stone

The form (Figure 3) has two groups of fields. Every field is optional. Fill in what you know and leave the rest as Unknown / not checked. The more you fill in, the more certain the answer. Each field shows what the property means (grey text) and how to measure it (HOW).

Figure 3. The input form: instrument readings with normal ranges, and picture choices for the optic character and for what you can see

Table 3. Input fields

6.1 Instant checks on your readings

As soon as you type an RI or SG value, a short note appears under the box (Figure 4):

  • Green "Fits: ..." lists the gems whose range includes your reading.
  • Orange warning: the value is unusual (no gem in the system has it, or it is above what most refractometers can read). Check your measurement.
  • Red error: the value is impossible (outside the allowed range). It appears when you leave the box, and the form will not be sent until you correct it.

Under each box a Normal range line shows the range of readings covered by the system (for example RI 1.515 - 1.990 for gems). The link See the range for each gem opens the ranges of every gem in a new tab, so your form is kept.

Ticking Over the limit (no reading) greys out the RI box and shows which gems read above the refractometer's limit (zircon, cubic zirconia and some garnets).

Figure 4. Readings checked as you type (top) and the "Over the limit" option (bottom)

Below the fields are three action panels: Identify my stone, Check a claim (choose a gem in the list, then Verify) and Ask me step by step. Clear the form empties all fields.

7.3 Using the reasoning diagram

Figure 6. Forward-chaining diagram

Your inputs are the blue boxes at the top. Each dark oval is a rule; its gold number shows the order in which it fired. Arrows show which facts made the rule fire and which new fact it added. Use the buttons:

  • Play step by step: replays the reasoning automatically, one rule at a time, with a caption explaining each step.
  • Back / Next: move one step at a time yourself.
  • Show all: shows the complete diagram again.

Hover the mouse over any box to see its full details.

7.4 When some data is missing

If you leave out the RI, SG or optic character, the system cannot confirm a species. Instead it lists Ranked possibilities (Figure 7): every gem consistent with what you entered, ordered by certainty, with the evidence for each.

Above the list, the yellow Most useful next measurement box tells you which missing measurement would narrow the list down best, and what each candidate would read. For example, for a red, singly refractive stone it advises measuring the refractive index, because spinel reads 1.712-1.736 and garnet 1.730-1.890.

Figure 7. Ranked possibilities and the most useful next measurement for a red, singly refractive stone

8. Checking a claim (Verify)

  1. Fill in the fields you know.
  2. In the Check a claim panel choose the gem the seller claims, e.g. Ruby.
  3. Press Verify.

The answer is a clear Yes (green tick) or No (red cross). For a No, the page shows the main reason, what your data points to instead, and a Why not? list tracing the failure back through the rules (Figure 8). The backward-chaining diagram shows the question at the top, the rules tried below it, and each condition marked proved (green), failed (red) or never checked (dashed grey).

Figure 8. A failed verification: a red spinel offered as a ruby

9. Step-by-step consultation

  1. Click Step by step in the top bar (or Ask me step by step on the home page).
  2. Choose what you want to find out. Find the species lets the system test one gem hypothesis after another. You can also choose a particular gem.
  3. Answer each question and press Answer, or press I don't know. The bar at the top shows how far you are ("Question 2 of at most 6").
  4. Made a mistake? Press Back to return to the previous question and change your answer.
  5. Open Why are you asking this? at any time to see which rule the system is testing and why it needs the answer (Figure 9).
  6. When the system has enough information it shows the answer, how many questions it needed, and a diagram of its reasoning. Change my last answer takes you back one step.

Figure 9. A consultation question with the progress bar, the Back button and the explanation

The system asks only what it needs. For example, when checking for ruby, answering Isotropic to the first question ends the consultation immediately, because a ruby must be doubly refractive.

10. Asking in plain English

Type a question into the box on the home page and press Ask. The system shows what it understood (Figure 10) and then answers. Examples:

  • Is my stone a sapphire? RI 1.765, SG 4.00, uniaxial and blue
  • What is a singly refractive red stone with SG 3.60?
  • Could it be glass? isotropic, RI 1.52, gas bubbles
  • Blue stone, RI over the limit, SG 4.70, uniaxial

Understood words include RI / refractive index, "over the limit", SG / specific gravity, singly or doubly refractive, uniaxial, biaxial, colour names, star, cat's eye, colour change, adularescence, silk, crystals, fingerprints, gas bubbles, curved lines, swirl marks, discoid fractures, clean, and gem names. Words the system did not use are listed so you can rephrase.

Figure 10. A plain-English question and how it was understood

InputRI 1.718, SG 3.60, Isotropic, Red; claim: Ruby
ResultNo - the stone does not match ruby. Main reason: a ruby must be doubly refractive (uniaxial) but the stone is singly refractive. The data points to Red spinel instead (Figure 8).

InputRI Over the limit (ticked), SG 4.70, Uniaxial, Blue, Crystals

Appendix A. Gem property facts for testing

This table lists the facts the system holds for every material in its knowledge base, so the system can be tested with any gem. For each one:

  • RI and SG are the reading ranges the rules use. The system also accepts readings slightly outside them (RI ±0.005, SG ±0.03) to allow for measurement error, but with lower certainty.
  • Try this reading is a sample input from the middle of the ranges. Enter it in the form (Section 6) and press Identify stone. For "RI over the limit", tick Over the limit (no reading) instead of typing an RI.
  • System result is what the system concludes for that reading, with its certainty. These results were produced by running the system on each sample.
  • Source is the reference the values were taken from (full references are in the project report).

Adding a colour from the list names the variety (for example corundum + red gives Ruby, chrysoberyl + colour change gives Alexandrite), and adding an inclusion lets the system judge whether the stone is natural or synthetic. Trying values outside the ranges, or a different optic character, shows how the system rejects a gem and explains why.
